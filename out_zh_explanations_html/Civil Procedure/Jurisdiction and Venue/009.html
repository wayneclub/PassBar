MBE 考点解析

Civil Procedure: Personal Jurisdiction

核心考点：对人管辖权 (Personal Jurisdiction)

联邦法院要对被告行使管辖权，必须满足宪法第十四修正案的正当程序条款 (Due Process Clause)。这通常分为两类：

🏠
一般管辖权
(General Jurisdiction)
被告“如同在地”
🎯
特定管辖权
(Specific Jurisdiction)
诉讼源于特定联系
1 分析一般管辖权 (General PJ)

规则：对于公司被告，只有在其“如同在地” (Essentially at Home) 的州，法院才拥有一般管辖权（即可以审理关于该被告的任何案件，无论案件发生在哪里）。

根据 Daimler AG v. Bauman，公司的“家”通常只有两个地方：

  • 注册成立地 (State of Incorporation) → State A
  • 主要营业地 (Principal Place of Business / HQ) → State B

结论：State C 只是存放库存的地方，不是公司的“家”。因此，State C 没有一般管辖权。

2 分析特定管辖权 (Specific PJ)

规则：如果被告不是“在家”，法院只能行使特定管辖权。这要求：

  1. 被告与法院地州有最低限度联系 (Minimum Contacts)。
  2. 原告的诉讼请求源于 (Arise out of) 或关联于这些联系。

本案应用：

  • 联系：公司在 State C 存放库存（满足最低联系）。
  • 关联性：诉讼是关于“外国发生的袭击”。袭击行为与“在 State C 存放鞋子”没有任何因果关系。

结论：诉讼请求并非源于被告在 State C 的联系。因此，State C 没有特定管辖权。

✅ 正确答案：选项 D

Yes, because the employee's claim does not arise out of the shoe company's contacts with State C and the shoe company is not domiciled in State C.

这个选项完美概括了上述两步分析：

  • 因为诉讼与 State C 的联系无关 → 无特定管辖权。
  • 因为公司不在 State C 定居（Domiciled/At Home）→ 无一般管辖权。

既无一般管辖权也无特定管辖权，法院必须批准驳回起诉的动议。

陷阱 A 错误原因：虽然有“最低限度联系”（存库存），但忽略了特定管辖权的第二个要素——Nexus（关联性）。仅仅有联系是不够的，诉讼必须由该联系产生。
陷阱 B 错误原因：混淆了“做生意”和“定居”。公司在某地有库存或做生意并不等于在该地“定居” (Domiciled)。定居仅限于注册地和总部。
陷阱 C 错误原因：说法太绝对。虽然 State C 没有管辖权，但 State A（注册地）和 State B（总部）拥有一般管辖权，可以审理该外国侵权案件。
💡 MBE 考试技巧：
看到 Personal Jurisdiction 题目，先画出公司的“家”（Inc + PPB）。如果案发地不在“家”里，立即检查案发事实是否与法院地州的商业活动有因果关系。如果没有关系，通常就没有管辖权。
