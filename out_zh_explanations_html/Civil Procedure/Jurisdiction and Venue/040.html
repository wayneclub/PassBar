MBE 考点解析

多元性管辖权与公民身份判定

⚖️ 核心法律规则 (Key Legal Rule)

联邦法院的多元性管辖权 (Diversity Jurisdiction) 要求：

  1. 争议金额超过 $75,000；且
  2. 原告与被告之间必须具有完全的公民身份多样性 (Complete Diversity)。

关键区别：
• 公司 (Corporation)：注册地 + 主要营业地。
• 合伙企业 (Partnership)：每一个合伙人的户籍所在地。

📝 案情逻辑推演

1
确定原告身份：
原告是一家公司，注册地和主要营业地都在 State A。因此，它是 State A 的公民。
2
确定被告身份（考点核心）：
被告是一家合伙企业（非法人社团）。根据最高法院判例 Carden v. Arkoma Assocs.，合伙企业的公民身份取决于其所有合伙人的户籍 (Domicile)。

题目指出：在起诉前，一名合伙人已永久迁居至 State A。
3
判定管辖权：
由于该合伙人是 State A 公民，该合伙企业也被视为 State A 公民。
结果：原告 (State A) vs. 被告 (State A)。
结论：完全多样性 (Complete Diversity) 被破坏，联邦法院无管辖权。
✅ 正确答案：D

支持动议，因为公司与合伙企业不具备多样性。

🚫 为什么其他选项是错的？

选项 A (错误)：
虽然争议金额 ($30k + $60k = $90k) 满足要求，但如上所述，双方公民身份重叠，不满足多样性要求。

选项 B (错误)：
属事管辖权 (Subject-Matter Jurisdiction) 永远不会因为未在答辩状中提出而放弃 (Waived)。根据《联邦民事诉讼规则》第12(h)(3)条，法院或当事人可在诉讼的任何阶段提出此问题。

选项 C (错误)：
关于争议金额 (Amount in Controversy)：单一原告起诉单一被告时，可以将所有索赔金额合并计算 (Aggregation)。$30,000 + $60,000 = $90,000，已超过 $75,000 的门槛。因此，金额不是驳回的理由。

🎓 考试技巧 (Exam Tip)

在 MBE 考试中看到合伙企业 (Partnership) 或有限责任公司 (LLC) 作为当事人时，立即警惕！不要套用公司的规则。

实体类型 公民身份判定标准
公司 (Corp) 注册地 + 主要营业地 (PPB)
合伙/LLC 每一个成员/合伙人的户籍地

*只要有一个合伙人与原告同州，多样性即告破裂。
