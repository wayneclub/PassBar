MBE 考点解析

Civil Procedure: Personal Jurisdiction

⚖️ 核心法律规则

对人管辖权 (Personal Jurisdiction) 可以通过被告的同意 (Consent) 建立。最常见的明示同意形式之一是合同中的法院选择条款 (Forum-Selection Clause)。

只要该条款并非通过欺诈手段诱导签署，且执行该条款不违反基本公平原则，联邦法院通常会认定其有效并据此行使管辖权。

案情关键点分析

本题的解题关键在于区分两个文件：

  1. 抵押贷款合同 (Mortgage)： 被告声称签名是伪造的。如果仅依据此文件，管辖权可能存在争议。
  2. 预审批申请 (Preapproval Application)： 被告承认 (Admits) 签署了此文件。

预审批申请中包含了明确的法院选择条款，规定所有涉及该申请过程的争议均在 State A 解决。由于被告承认签署了包含该条款的文件，他已经明示同意 (Expressly Consented) 了 State A 法院的管辖权。

选项深度解析
选项 A (正确)：
法院应驳回 (Deny) 房主的动议。因为房主签署了包含法院选择条款的预审批申请，这构成了对 State A 管辖权的明示同意。即使他后来没有完成贷款流程，该条款依然有效覆盖了“申请过程中”产生的争议。
选项 B (错误)：
虽然房主在 State A 有分时度假屋 (Time-share)，但这并不自动赋予法院对本案的管辖权。
  • 特定管辖权 (Specific Jurisdiction)： 本案诉讼并非源于该分时度假屋，而是源于另一处房产的抵押贷款纠纷。
  • 一般管辖权 (General Jurisdiction)： 仅拥有财产不足以让被告在 State A 被视为“在家” (At home)。
选项 C (错误)：
这是一个错误的法律陈述。根据最高法院判例（如 The Bremen v. Zapata Off-Shore Co. 和 Carnival Cruise Lines, Inc. v. Shute），法院选择条款在联邦法院通常是可执行的 (Enforceable)，除非证明其极度不公或由欺诈取得。
选项 D (错误)：
虽然被告居住在 State B，但这只意味着 State A 对其没有基于住所的一般管辖权。它并不妨碍被告通过合同同意接受 State A 的管辖。同意 (Consent) 是建立管辖权的独立基础，无需考虑居住地。
💡 MBE 考试技巧

在处理 Personal Jurisdiction 问题时，请遵循以下思维导图：

  1. 第一步：看是否有“同意” (Consent)？
    （例如：自愿出庭、未及时提出异议、或本题中的法院选择条款）。如果有有效同意，分析结束，法院有管辖权。
  2. 第二步： 如果没有同意，再分析长臂法案 (Long-arm statute) 和宪法正当程序 (Due Process) 下的最低限度联系 (Minimum Contacts)。

陷阱警示： 不要被“被告声称签名伪造”迷惑。仔细看题目，他承认签署了另一份带有管辖条款的文件。
