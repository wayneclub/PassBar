*Binding Effect of Class Action Judgments*

⚖️ 法律依据与推理

1
本案涉及的是根据联邦民事诉讼规则第23条(b)(3)款认证的类案诉讼。该款适用于“共同问题在任何个人问题上占主导地位，且类案诉讼是公平有效解决争议的最佳方法”的情况。题目明确指出，类案诉讼的认证是基于“共同问题占主导地位”，这正是Rule 23(b)(3)的特征。
2
对于Rule 23(b)(3)类案诉讼，法律要求必须向所有可识别的类案成员提供最佳可行通知 (best practicable notice)，告知他们有权选择退出 (opt out)类案诉讼。如果类案成员收到适当通知但未选择退出，那么该成员将受最终判决的约束 (bound by the final judgment)，无论判决结果对类案有利还是不利。这种约束力是既判力 (res judicata)原则的体现，旨在避免重复诉讼和确保判决的终局性。
3
本案中，类案成员收到了适当通知，但未选择退出类案诉讼。这意味着她自愿选择成为类案的一部分，并接受其结果。由于州A联邦法院已对该公司作出了有利判决，该判决对所有未退出的类案成员都具有约束力。因此，该类案成员在州B提起的诉讼应被驳回，因为其主张已被先前的判决排除 (precluded)。
⚠️ 核心规则 / 陷阱警示： 在联邦民事诉讼规则第23条(b)(3)款类案诉讼中，如果类案成员收到适当通知并有机会选择退出，但未行使该权利，则该成员将受最终判决的约束。这是MBE中关于类案诉讼既判力的一个常见考点。务必区分不同类型的类案诉讼及其通知和退出权利。

📊 类案诉讼类型对比

类型 (Rule 23(b)) 主要特征 通知要求 退出 (Opt Out) 权利 判决约束力
(b)(1)
Prejudicial Risk		 单独诉讼会造成不一致判决或损害缺席成员利益 可选 无 对所有成员有约束力
(b)(2)
Final Equitable Relief		 被告行为对整个类案适用，寻求禁令或宣告性救济 可选 无 对所有成员有约束力
(b)(3)
Common Question		 共同问题占主导，类案是最佳解决方式 必须 (最佳可行通知) 有 对所有未退出成员有约束力
🔑 独立案例 / 扩展情景： 关于缺席类案成员的最低联系 (minimum contacts)问题，美国最高法院在 Phillips Petroleum Co. v. Shutts 一案中裁定，对于Rule 23(b)(3)类案诉讼中的缺席原告，只要他们收到适当通知并有机会选择退出，就不需要与审理法院所在州有最低联系。这是因为缺席原告的负担远小于被告，且他们的利益由代表原告充分代表。因此，即使本案中的类案成员与州A没有最低联系，只要她收到通知且未退出，她仍受判决约束。

Choice D is correct: For the company, because the class member did not opt out of the class action.

A选项错误：支持类案成员，因为她未明确同意成为类案诉讼的成员。 在Rule 23(b)(3)类案诉讼中，缺席成员通常不需要“明确同意”才能成为类案成员并受判决约束。相反，他们通过“不退出”来表示同意。只要收到适当通知并有机会退出，未退出即视为接受类案的代表和判决的约束力。
Choice B is wrong: For the class member, because she did not have minimum contacts with State A.
B选项错误：支持类案成员，因为她与州A没有最低联系。 根据最高法院在Phillips Petroleum Co. v. Shutts案中的裁决，对于Rule 23(b)(3)类案诉讼中的缺席原告，只要他们收到适当通知并有机会选择退出，就不需要与审理法院所在州有最低联系。因此，缺乏最低联系并不能阻止判决对其的约束力。
Choice C is wrong: For the company, because a judgment in this type of class action is enforceable against all members of the class.
C选项错误：支持公司，因为此类类案诉讼的判决对所有类案成员都可执行。 这个选项表述不完全准确。虽然Rule 23(b)(3)类案诉讼的判决对所有未退出的类案成员都具有约束力，但它并非对“所有成员”都可执行，因为那些选择退出的成员是不受约束的。因此，D选项的表述更精确地指出了判决约束力的前提条件（未退出）。
🎓 考试技巧 / 助记： 记忆Rule 23(b)下不同类型类案诉讼的通知 (Notice)和退出 (Opt-out)权利至关重要。只有Rule 23(b)(3)类案诉讼才强制要求提供最佳可行通知和退出权利。一旦成员收到通知但未退出，他们就“买入”了类案的结果，无论输赢。
