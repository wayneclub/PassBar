Civil Procedure

集体诉讼的认证规则

Class Action Certification under FRCP 23
正确答案：D

是的，上诉法院很可能会推翻该认证令，因为该集体诉讼寻求的是个体化的金钱损害赔偿 (Individualized Monetary Damages)。

核心考点解析

本题考察的是《联邦民事诉讼规则》第23条 (FRCP 23) 中关于不同类型集体诉讼的认证标准，特别是 Rule 23(b)(2) 与金钱赔偿的关系。

Rule 23(b)(2) "禁令类" 集体诉讼 此类诉讼适用于被告的行为普遍适用于整个集体，因此禁令救济 (Injunctive Relief) 或 宣告性救济 (Declaratory Relief) 对整个集体是适当的。

关键规则：

  • 适用范围： Rule 23(b)(2) 主要用于解决民权案件或要求停止某种行为的案件，其核心在于救济的“不可分割性”。
  • 金钱赔偿的限制： 如果原告寻求金钱赔偿，只有当这些赔偿是附带的 (Incidental) 且不需要复杂的个体计算时，才可能被允许。
  • 禁止个体化赔偿： 如果金钱赔偿需要对每个成员进行单独的证据听证或计算（即“个体化”），则不能根据 Rule 23(b)(2) 进行认证。

重要判例：Wal-Mart Stores, Inc. v. Dukes (2011)

最高法院明确指出，当集体成员寻求个体化的金钱救济 (Individualized Monetary Relief) 时，不能根据 Rule 23(b)(2) 认证集体诉讼。此类索赔通常属于 Rule 23(b)(3)，后者提供了更严格的程序保护（如通知和退出权）。

案情应用

在本案中，原告不仅寻求禁令，还要求每对伴侣获得 $5,000 到 $20,000 不等的赔偿。这意味着：

  1. 法院必须单独审查每对伴侣的具体情况来确定赔偿额。
  2. 这属于个体化金钱损害赔偿，而非仅仅是禁令的附带产物。
  3. 因此，地区法院将其认证为 "Final Equitable Relief" (Rule 23(b)(2)) 集体诉讼是滥用自由裁量权。

干扰项分析

选项 A & C (管辖权)
错误。本案基于联邦法规提起，存在联邦问题管辖权 (Federal Question Jurisdiction)，不需要满足争议金额 (Amount-in-Controversy) 要求。虽然管辖权存在，但这不能解决认证类型错误的问题。
选项 B (最终判决规则)
错误。通常上诉需要等到最终判决 (Final Judgment Rule)。但是，Rule 23(f) 提供了一个例外，允许上诉法院在地区法院下达批准或拒绝集体诉讼认证的命令后，立即受理中间上诉 (Interlocutory Appeal)。

MBE 考试技巧

看到 Rule 23(b)(2)（禁令类集体诉讼）时，立即检查原告是否要求金钱赔偿。

  • 如果是统一的、附带的赔偿（如法定固定罚款），可能允许。
  • 如果是因人而异的赔偿（如本题的 $5k-$20k），则必须走 Rule 23(b)(3) 通道（需要 Predominance 和 Superiority），不能走 (b)(2)。
