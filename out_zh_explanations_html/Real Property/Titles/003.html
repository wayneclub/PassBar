MBE 考点解析：不动产产权优先权

核心考点：庇护规则 (Shelter Rule) 即使受让人知悉先前的未登记权益（即不是善意购买人），如果他是从善意购买人 (BFP) 手中获得产权，他将受到该 BFP 身份的“庇护”，从而获得与 BFP 同等的优先权。

1. 案情时间线梳理

7年前： 男子 -> 女性 (Woman)
未登记 未占有
虽然她是BFP，但未完善产权。
5年前： 男子 -> 邻居 (Neighbor)
BFP 已登记
邻居不知情且支付对价，成为BFP。
2年前： 邻居 -> 朋友 (Friend)
知情
朋友知道女性的事，但他从邻居处购买。

2. 法律推理逻辑

第一步：确定“邻居”的地位
该司法管辖区是通知型 (Notice Statute)。邻居购买土地时，女性未登记也未占有，邻居不知情且支付了对价。因此，邻居是善意购买人 (BFP)。根据通知型法规，邻居的产权优先于女性的产权。
第二步：应用“庇护规则” (Shelter Rule)
朋友从邻居手中购买土地。虽然朋友知情 (had notice)（这通常会让他失去BFP资格），但因为他的转让人（邻居）拥有优先权，朋友继承了邻居的法律地位。

结论： 既然邻居能战胜女性，朋友作为邻居的继承者，也能战胜女性。

3. 为什么选 B？

正确答案是 B。女性败诉的根本原因在于邻居的产权优于女性。一旦邻居确立了优先权，这种优先权就通过转让传递给了朋友（Shelter Rule）。

4. 为什么其他选项是错的？

  • 选项 A (占有)： 错误。产权优先权由登记法 (Recording Acts) 决定，而不是看谁先占有土地。占有只是“推定通知”的一种形式，但在此案中不是决定性因素。
  • 选项 C (朋友知情)： 这是最大的干扰项。通常知情者不能胜诉，但庇护规则是例外。只要前手是清白的 BFP，后手的知情状态就被“洗白”了。
  • 选项 D (契约类型)： 错误。担保契约 (Warranty Deed) 和 免责契约 (Quitclaim Deed) 仅影响卖方对买方的赔偿责任，不决定产权对第三方的优先顺位。在MBE中，持免责契约的人也可以是 BFP。
💡 考试技巧 (Exam Tip)
看到 "Notice"（知情）字眼时，不要立刻判定该买家败诉。一定要往回看他的前手 (Grantor)。如果前手是 BFP，后手自动赢，无论后手是否知情、是否登记、是否是赠与受赠人。这就是“庇护规则”的威力。
