MBE 考点解析

Mortgages & Security Devices
正确答案：B

法院不会批准该动议，因为整块四英亩土地都受银行的优先抵押权（Senior Mortgage）约束。

核心考点：资产聚合规则 (Marshalling of Assets)

本题最大的干扰项是关于 Marshalling（资产聚合/双重基金规则）。

规则定义：当优先债权人（Senior Creditor）拥有两个或以上的资金来源（Funds/Properties）来清偿债务，而次级债权人（Junior Creditor）只能依靠其中一个时，公平原则（Equity）要求优先债权人先执行次级债权人无法触及的那个资产。

适用情况
Senior: 拥有资产 A + B
Junior: 仅拥有资产 A
⬇️
Senior 必须先卖 B
本题情况
Senior: 拥有资产 X
Junior: 拥有资产 X
⬇️
规则不适用

关键点：本案中，虽然土地有4英亩，但在法律上它被视为单一基金（Single Fund）。两家银行的抵押权都覆盖整个地块。因此，不存在“两个基金”供优先债权人选择。

选项深度解析

选项 A 错误 Purchase-Money Mortgage (PMM)

理由：PMM 是指用于担保“购买该房产资金”的贷款。本题中，女子已经拥有土地多年后才进行抵押贷款。因此，这不是 PMM，不享有 PMM 的超级优先权。

选项 D 陷阱 "Two Funds" Rule

理由：这是本题设计的陷阱。虽然金融公司试图主张将土地“分割”看待，但法律上抵押物是整体的。除非有明确的分割条款，否则优先抵押权人（Bank）有权拍卖整个抵押物来受偿，无需为了照顾次级债权人而承担分割拍卖可能带来的风险（如售价降低）。

选项 C 错误 Pro Rata Foreclosure

理由：法院通常不会强迫优先债权人进行部分止赎（Partial Foreclosure），因为这会改变合同条款并可能损害其利益。优先债权人有权处置全部抵押物。

💡 MBE 考试技巧：
看到次级债权人要求优先债权人“先卖别的”或“只卖一部分”，立刻联想 Marshalling 规则。

但必须检查前提：是否有两个独立的资产（Two Funds）？ 如果只是同一个资产的不同部分，该规则通常不适用。
