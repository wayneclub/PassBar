MBE 考点解析

Mortgages & Security Devices

⚖️ 核心考点：抵押债务的承担

当抵押财产被转让时，买方（Grantee）对现有抵押债务的责任取决于契据中的措辞。这是 MBE 考试中关于不动产抵押的高频考点。

1. Subject to the Mortgage
(在抵押权负担下受让)
买方不承担个人责任。如果违约，银行可以止赎（卖房），但不能追究买方的个人财产来填补差额（Deficiency）。
2. Assume the Mortgage
(承担抵押)
买方承担个人责任。买方成为主要债务人（Primary Liable），原卖家成为保证人（Surety）。如果止赎后有差额，买方需赔偿。
🔍 题目逻辑分析

案情关键点：契据中明确写明买方同意 "to assume the existing mortgage debt"（承担现有抵押债务）。

法律后果：一旦买方签署或接受了包含“Assume”条款的契据，他就明确同意对债务负责。因此，当止赎拍卖所得不足以偿还银行贷款时（Deficiency），买方必须自掏腰包补足差额。

✅ 选项详解
选项 C (正确)

"Yes, because the buyer assumed the mortgage..."
这是对法律规则的直接应用。因为买方“承担”（Assumed）了抵押，所以他成为了主要责任人，必须对不足额（Deficiency）负责。

选项 A (错误)

该选项错误地认为原业主（卖家）是唯一的责任人。事实上，在“承担抵押”的情况下，买方变成主要责任人，卖家变成次要责任人（Surety）。只有在买方无法赔偿时，银行才会找卖家。

选项 B (错误陷阱)

陷阱点：“买方没有签署本票（Promissory Note）”。
虽然买方没有签原始的借条，但他通过接受包含承担条款的契据（Deed）这一行为，已经构成了承担债务的合同义务。不需要重新签署本票即可产生个人责任。

选项 D (错误概念)

该选项提到了 Novation（债务更新/更替）。
Novation 需要银行（Lender）、卖家和买方三方共同达成协议，明确免除卖家的责任并由买方替代。仅仅是买卖双方之间的转让和承担，并不构成 Novation，卖家并未被银行完全免责（只是退居次位）。

💡 考场实战技巧 在阅读 MBE 抵押权转让题目时，请立即寻找关键词：
  • 如果是 "Subject to" ➡️ 买方无个人责任 (No Personal Liability)。
  • 如果是 "Assume" ➡️ 买方有个人责任 (Personal Liability)。
注意：除非题目明确说银行签署了 Release 或 Novation，否则原卖家（Original Mortgagor）永远保持连带或次要责任，不会完全脱身。
